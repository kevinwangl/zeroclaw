### 应急预案

**如果网络失败**:
1. 立即切换到备用 Demo 视频
2. 说: "让我们看一下预录的演示"
3. 播放视频
4. 继续讲解

**如果 Agent 响应慢**:
1. 说: "正在获取真实数据，需要一点时间"
2. 利用等待时间讲解架构
3. 指向终端日志，解释正在做什么

**如果 Agent 出错**:
1. 说: "看来遇到了一个问题，这正好演示故障排查"
2. 查看日志，找出错误
3. 解释如何排查和解决
4. 切换到备用 Demo 视频

## 📝 演讲技巧

### 开场技巧
1. **先演示，再讲原理**: Demo 先行，吸引注意力
2. **痛点共鸣**: "你们是不是也遇到过..."
3. **价值明确**: 3 句话说清楚为什么重要

### 讲解技巧
1. **慢一点**: 操作时放慢速度，让观众看清
2. **指出来**: 用鼠标指向关键信息
3. **重复关键点**: 重要的话说 3 遍

### 互动技巧
1. **提问**: "你们觉得这个方案怎么样？"
2. **征集经验**: "有人试过类似的方法吗？"
3. **现场投票**: "你们会选哪个方案？"

### 时间控制
- 开场: 30秒
- Demo: 3-4分钟
- 讲解: 根据剩余时间调整
- Q&A: 预留 5-10分钟
