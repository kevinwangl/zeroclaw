# AI Agent 工具集成实践分享方案

## 📋 分享材料结构建议

### 方案 A: 技术深度分享（45分钟）

**适合**: 技术团队内部、架构评审

#### 1. 开场（5分钟）
- **Demo 先行**: 现场演示钉钉发送 "分析贵州茅台" → 3分钟后收到报告
- **痛点引入**: 传统方式需要手动下载数据、Excel 计算、写报告
- **价值主张**: AI Agent 自动化 + 真实数据 = 自然语言驱动的财务分析

#### 2. 架构设计（15分钟）
- **系统架构图**: 用户 → Channel → Provider → Tool → 外部工具 → 数据源
- **技术选型**: 为什么选 ZeroClaw（Rust）、Kiro CLI、akshare
- **关键决策**: 包装脚本 vs 直接调用、MANDATORY 提示、白名单权限

#### 3. 核心改造点（20分钟)
- **改造 1**: 工具集成（包装脚本设计）
- **改造 2**: 提示工程（MANDATORY 强制指令）
- **改造 3**: 权限配置（allowed_roots 白名单）
- **改造 4**: 日志增强（RUST_LOG 配置）
- **改造 5**: 速率限制配置（max_actions_per_hour）

每个改造点包含:
- ❌ 初始方案 + 问题
- ✅ 最终方案 + 代码示例
- 💡 经验总结

#### 4. 踩坑与解决（15分钟）
- **坑 1**: Agent 不调用工具 → MANDATORY 提示
- **坑 2**: 日志不完整 → RUST_LOG 配置
- **坑 3**: 工具批准失败 → trustAllTools
- **坑 4**: 响应慢 → 性能分析与优化
- **坑 5**: 速率限制 → max_actions_per_hour 配置

#### 5. 可复用模式（5分钟）
- **模式 1**: 外部工具集成配置模板
- **模式 2**: 强制提示模板
- **模式 3**: 包装脚本模板
- **模式 4**: 日志增强模板

#### 6. Q&A（5-10分钟）

**适合**: 团队培训、技能提升

#### 第一部分: 理论讲解（30分钟）
- 同方案 A 的 1-2 部分

#### 第二部分: 动手实践（90分钟）
**练习 1**: 配置 ZeroClaw 基础环境（20分钟）
- 安装 ZeroClaw
- 配置 config.toml
- 测试 CLI 模式

**练习 2**: 集成简单工具（30分钟）
- 写一个简单的 Bash 脚本（例如: 天气查询）
- 配置 allowed_roots
- 写 MEMORY.md 提示
- 测试工具调用

**练习 3**: 集成财务分析工具（40分钟）
- 按照完整流程配置
- 测试钉钉集成
- 查看日志排查问题

#### 第三部分: 总结与讨论（30分钟）
- 各组分享遇到的问题
- 讨论可能的应用场景
- 规划下一步行动

## 💡 分享技巧

### 开场技巧
1. **Demo 先行**: 先展示效果，再讲原理
2. **痛点共鸣**: 从听众熟悉的问题切入
3. **价值明确**: 3 句话说清楚为什么重要

### 讲解技巧
1. **对比展示**: 初始 vs 最终，问题 vs 解决
2. **代码精简**: 只展示关键代码，完整代码放附录
3. **图胜于表**: 能用图就不用表，能用表就不用文字

### 互动技巧
1. **提问引导**: "你们遇到过类似问题吗？"
2. **现场投票**: "你们会选哪个方案？"
3. **经验征集**: "有人试过其他方法吗？"

### 收尾技巧
1. **总结 3 点**: 最重要的 3 个收获
2. **行动建议**: 明天就能做的 1 件事
3. **资源分享**: 代码、文档、联系方式
